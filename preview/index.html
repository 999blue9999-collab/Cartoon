Verification

Unity runs Nore.Core.SelfTests on Play. The browser runs the shared combat checks below; node tools/sim_harness.mjs runs the full 9-check headless harness, and python3 tools/validate_data.py validates every JSON reference.

Architecture

Core (fixed-point, RNG) → Data (JSON registry) → Economy / Military / Combat / World → Runtime
Unity: MonoBehaviour + IMGUI, 10 Hz fixed accumulator, save/load + offline catch-up
Combat: aggregated squad stacks (struct-of-arrays) + spatial hash, integer-only, seeded RNG
Browser: preview/sim.mjs mirrors docs/COMBAT_SPEC.md; C# remains authoritative
